# Kulue Driver — test demo

Compiled web demo of the Kulue driver app with sample data, for stakeholder testing.
Open: https://awsm-vasim.github.io/kulue-driver-demo/

Built from the private `kulue-driver` repo with:
`flutter build web --release --dart-define=DEMO=true --dart-define=MAPS_KEY= --no-web-resources-cdn --pwa-strategy=none --base-href /kulue-driver-demo/`
No source code and no API keys are in this repo. Nothing in the demo touches real data.
